Support

Setup, troubleshooting and responsible bug reports.

Getting started

  1. Install Better Browser History and review the disclosure that opens in Settings.
  2. Select I understand — enable private history if you want capture to begin.
  3. Browse normally, then open chrome://history or choose the extension icon.
  4. Use Settings to pause capture, exclude sites, adjust retention, export a backup or clear all data.

New Tab or homepage troubleshooting

Better Browser History v1.3.0 and later overrides only Chrome's History page. It does not declare a New Tab, homepage, startup-page or search override.

  1. Open chrome://extensions and confirm Better Browser History shows version 1.3.1 or later.
  2. Remove any older unpacked copy of the extension, then reinstall the current release.
  3. Check chrome://extensions for another extension that is allowed to replace New Tab.
  4. Review Chrome's Settings → On startup, Appearance and Search engine sections.

Search is missing a page

Confirm capture and page-content capture are enabled, the site is not excluded and the page uses an http or https URL. Chrome blocks extensions from capturing protected browser pages such as chrome:// pages and the Chrome Web Store.

Report a problem

Search existing reports or open a new issue in the GitHub support tracker. Include the extension version, Chrome version, operating system, expected behavior, actual behavior and reproduction steps.

Protect your privacy: Do not attach exported history, private URLs, page contents, passwords or other sensitive information to a public issue.

Security reports

For a suspected vulnerability, use the repository's private security advisory form instead of filing a public issue.
